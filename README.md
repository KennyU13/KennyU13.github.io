## Installation Locale

```bash
npm install
npm run dev
```

Puis ouvrir:

```text
http://localhost:5173
```

## Build Production

```bash
npm run build
npm run preview
```

## Lancement Avec Docker

Mode developpement:

```bash
docker compose up portfolio-dev
```

Puis ouvrir:

```text
http://localhost:4000
```

Mode production:

```bash
docker compose up --build portfolio
```

Puis ouvrir:

```text
http://localhost:8080
```
